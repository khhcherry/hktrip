富豪九龍酒店 Check-in ➔ 樓下 Market Place 超市採買 ➔ 尖沙咀海濱長廊散策 ➔ 維多利亞港百萬夜景。

餐食 (無牛魚)

晚餐：新記冰室 (尖沙咀) — 招牌芝士汁豬扒撈丁、瑞士汁雞翼。

宵夜：無安排 (專注休息儲備體力)。

Day 02

中秋古蹟巡禮

屏山文物徑 ➔ 元朗老餅家 ➔ 葵廣 ➔ 賞月

交通 (全順向無折返)

屯馬綫直達天水圍站 ➔ 坑尾村站搭輕鐵直達元朗大馬路 ➔ 屯馬綫直達葵芳站 ➔ 屯馬/荃灣綫回尖沙咀。

景點

屏山文物徑 (聚星樓、鄧氏宗祠) ➔ 搭乘特色輕鐵 ➔ 元朗恆香/奇華買月餅 ➔ 葵涌廣場 ➔ 尖沙咀海濱賞月。

餐食 (無牛魚)

  • 早：紅茶/華嫂冰室 (菠蘿油/豬扒包)
  • 午：好到底麵家 (米其林蝦子撈麵、鮮蝦水餃)
  • 下午茶：葵廣小吃 (冷麵/爆漿吐司/格仔餅)
  • 晚：妹記大排檔 (避風塘炒肉蟹、脆皮炸豬手)
Day 03

園林與藝術聚落

早茶 ➔ 沙田馬場 ➔ 志蓮淨苑 ➔ 土瓜灣牛棚

交通 (全順向屯馬綫)

港鐵上環站 ➔ 沙田馬場專綫 ➔ 鑽石山站(志蓮淨苑) ➔ 屯馬綫直達土瓜灣站 ➔ 尖東站。

景點

永吉街檸檬王蜜餞/香薰 ➔ 沙田馬場體驗 ➔ 志蓮淨苑與南蓮園景(唐代木造建築) ➔ 牛棚藝術村(紅磚古蹟) ➔ 十三街。

餐食 (無牛魚)

  • 早：聚點坊點心 (水晶蝦餃、叉燒包、排骨)
  • 午：馬場看台快餐 (燒鴨叉燒雙拼/玫瑰豉油雞)
  • 下午茶：志蓮素軒 (品茗、洛神花凍)
  • 晚：哥登堡餐廳 (豬扒鐵板) 或 楚城海鮮飯店

Day 04

離島慢活與中環

南丫島 ➔ 中環大館/PMQ ➔ Bakehouse

交通

天星小輪至中環 ➔ 搭渡輪直達南丫島榕樹灣 ➔ 渡輪回中環 ➔ 天星小輪回尖沙咀。

景點

南丫島榕樹灣大街慢活 ➔ 中環街市 ➔ 大館百年古蹟群 ➔ PMQ元創方 ➔ 文武廟 ➔ 維港夜景。

餐食 (無牛魚)

  • 早：澳門茶餐廳 (現烤葡汁豬扒包/葡式蛋撻)
  • 午：南島書蟲(蔬食) 或 南丫天虹(海鮮)
  • 下午茶：Bakehouse爆漿蛋撻 + 蘭芳園西多士
  • 晚：沾仔記 (巨無霸鮮蝦雲吞麵)
