美景與美食尋味之旅

Day 01

抵達東方之珠

飯店周邊巡禮 ➔ 維港百萬夜景漫步

交通

高雄小港機場 ➔ 香港國際機場 ➔ 城巴 A21 巴士（麼地道站下車）➔ 步行至富豪九龍酒店。

景點

富豪九龍酒店 Check-in ➔ 樓下 Market Place 超市採買 ➔ 尖沙咀海濱長廊散策 ➔ 維多利亞港百萬夜景。

餐食 (無牛魚)

晚餐：新記冰室 (尖沙咀) — 招牌「芝士汁豬扒撈丁」、「瑞士汁雞翼」。

宵夜：無安排 (專注休息儲備體力)。

Day 02

中秋古蹟巡禮

屏山文物徑 ➔ 元朗老餅家 ➔ 葵廣 ➔ 賞月

交通 (全順向無折返)

屯馬綫直達天水圍站 ➔ 坑尾村站搭輕鐵直達元朗大馬路 ➔ 屯馬綫直達葵芳站(葵廣) ➔ 回尖沙咀。

景點

屏山文物徑 (聚星樓、鄧氏宗祠) ➔ 搭乘特色輕鐵體驗 ➔ 元朗大馬路 (恆香老餅家/奇華買月餅) ➔ 葵涌廣場 ➔ 尖沙咀賞月。

餐食 (無牛魚)

  • 早：紅茶冰室 / 華嫂冰室 (香脆菠蘿油、豬扒包)
  • 午：好到底麵家 (米其林蝦子撈麵、鮮蝦水餃)
  • 下：葵廣小吃 (現撈冷麵、爆漿吐司、格仔餅)
  • 晚：妹記大排檔 (避風塘炒肉蟹、脆皮炸豬手)
Day 03

園林與藝術聚落

平價早茶 ➔ 沙田馬場 ➔ 志蓮淨苑 ➔ 土瓜灣牛棚

交通 (全順向屯馬綫)

港鐵上環站 ➔ 沙田馬場專綫 ➔ 鑽石山站(志蓮淨苑) ➔ 搭屯馬綫直達土瓜灣站(牛棚) ➔ 尖東站。

景點

檸檬王/兆成行香薰 ➔ 沙田馬場公眾席體驗 ➔ 志蓮淨苑與南蓮園景(唐代木造建築) ➔ 牛棚藝術村(百年紅磚聚落)。

餐食 (無牛魚)

  • 早：聚點坊點心 (水晶蝦餃皇、脆皮叉燒包、蒸排骨)
  • 午：沙田馬場看台餐廳 (脆皮燒鴨叉燒雙拼飯)
  • 下：志蓮素軒 (南蓮園景水月榭內品茗、素點)
  • 晚：哥登堡餐廳 (香煎豬扒鐵板) 或 楚城海鮮飯店
Day 04

離島慢活與中環

南丫島 ➔ 中環大館/PMQ ➔ Bakehouse

交通

天星碼頭搭小輪至中環 ➔ 搭渡輪直達南丫島 ➔ 渡輪回中環 ➔ 步行空橋 ➔ 天星小輪回尖沙咀。

景點

南丫島榕樹灣大街(文創慢活) ➔ 中環街市 ➔ 大館百年古蹟群 ➔ PMQ元創方 ➔ 文武廟 ➔ 沾仔記 ➔ 維港夜景。

餐食 (無牛魚)

  • 早：澳門茶餐廳 (招牌現烤葡汁豬扒包、熱絲襪奶茶)
  • 午：南島書蟲(人氣蔬食) 或 南丫天虹(蒜蓉蒸大蝦/炒蜆)
  • 下：Bakehouse 爆漿蛋撻 ＋ 蘭芳園法式西多士
  • 晚：沾仔記 (米其林必比登巨無霸鮮蝦雲吞麵)
Day 05

殖民秘境與採買

尖沙咀殖民秘境 ➔ 東薈城超市 ➔ 滿載而歸

交通

尖沙咀周邊漫步 ➔ 港鐵東涌綫直達東涌站 ➔ S1 專線巴士直達機場。

景點

九龍公園前英軍威菲路軍營 ＆ 文物探知館(白堊迴廊) ➔ 聖安德烈堂(百年教堂) ➔ 東薈城 TaSTe 超市採買。

餐食 (無牛魚)

  • 早午：翠園 (星光行海景：水晶鮮蝦餃皇、金牌流沙包)
  • 下：蘭芳園重慶大廈分店 (法式西多士、香脆豬扒包)
  • 晚：香港機場內餐廳 或 抵達高雄溫暖的家
